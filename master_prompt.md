# VISUAL DESIGN

Use a **bright, clean, modern technology aesthetic**.

The website should have:

* White background
* Very light gray sections
* Soft blue gradients
* Light cyan accents
* Occasional violet accents
* Dark navy typography
* Lots of whitespace
* Rounded cards
* Thin subtle borders
* Soft shadows
* Minimal glassmorphism
* Premium typography
* Clean icons

Primary color:

**Bright electric blue**

Secondary:

**Soft cyan / subtle violet**

Do NOT make it dark.

Do NOT make it overly flashy.

Do NOT use excessive gradients.

Do NOT use excessive animations.

Do NOT use generic stock photos of businessmen sitting around laptops.

The design should feel like a modern engineering startup.

Think:

**clean + intelligent + trustworthy + futuristic**

rather than:

**gaming website + cyberpunk + excessive neon.**

# 3D / INTERACTION REQUIREMENTS

Three.js should be used strategically in:

### Hero

Interactive PyForge engineering network.

### Our Work

Animated software pipeline for the Honda case study.

### Final CTA

Subtle particle/network background.

Optional:

Use small WebGL interactions when hovering over service cards.

Do not make every section 3D.

Performance is more important than visual complexity.

Use:

* Lazy loading
* Suspense
* Optimized geometries
* Low polygon counts
* Responsive canvas sizing
* Reduced motion support
* Mobile fallback

On low-powered/mobile devices, automatically reduce or disable intensive 3D effects.
