## 🛠️ This Repository — Website

This is the source code for the **PyForge marketing website**, built with:

| Tech | Purpose |
|---|---|
| [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org/) | UI framework |
| [Vite](https://vite.dev) | Build tool & dev server |
| [Tailwind CSS v4](https://tailwindcss.com) | Styling |
| [Framer Motion](https://www.framer.com/motion/) | Animations |
| [Three.js](https://threejs.org/) | 3D hero background |
| [Lucide React](https://lucide.dev/) | Icons |
| [Formspree](https://formspree.io) | Contact form backend |

### Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Production build
npm run build
```

### Deploy

The site is deployed on [Vercel](https://vercel.com). To redeploy:

```bash
npx vercel --prod
```
